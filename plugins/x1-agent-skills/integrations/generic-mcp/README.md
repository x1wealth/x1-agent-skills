# Generic MCP hosts

An OAuth-capable streamable HTTP host can connect to:

`https://mcp.x1wealth.com/mcp`

The remote X1 service owns authentication, household scope, and tool authority.
This repository contributes a portable workflow only. It does not proxy, clone,
deploy, or widen the X1 MCP surface. Never commit access tokens or X1 API keys.
Generic hosts are expected-compatible until a named version passes the exact
public-release qualification suite.
